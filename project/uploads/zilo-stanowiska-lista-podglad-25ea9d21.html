Odwzorowanie 1:1 z zilo-front-v2: DesktopDayView.vue, CalendarWorkspaceFilter.vue, DesktopListView.vue, SchedulerEvent.vue (list-layout) oraz palet z helpers/calendar.ts, helpers/colors.ts, styles/_colors.scss. Wszystkie px, wagi fontów i hexy pochodzą wprost z kodu.
1. Tag stanowiska — chip filtra (nad kalendarzem)
„Wszystkie stanowiska" (bez markera) + chipy per stanowisko z markerem koloru. Aktywny = obwódka blue-1 + tło blue-5.
Wszystkie stanowiska Pan Aleksander Pan Paweł Podnośnik 2 Lakiernia
Chip: padding:8px 12px border:1px #DCE0E6 radius:8px bg:#fff font:13px/400 color:#000 gap:8px. Hover: border #1D207C (blue-2). Aktywny: border #222693 (blue-1) + tło #F3F3FF (blue-5). Marker: 4×16 radius:2px, tło = border koloru stanowiska. „Wszystkie stanowiska" — bez markera.
2. Lista wizyt (widok listy)
Grupa per dzień: nagłówek (dzień + data) z licznikiem, pod nim wizyty. Każda wizyta = kolor stanowiska (tło + pasek), status jako kropka + etykieta.

10:30–12:00 BMW X3 Wymiana klocków i tarcz — przód Nowe
12:00–13:00 VW Golf Przegląd okresowy Zakończone
13:00 ---- ---- Diagnostyka komputerowa Wydane
Kontener listy: flex-column gap:16px, overflow-y:auto, padding-right:12px.
Grupa (dzień): bg:#fff border:1px #DCE0E6 radius:8px. Nagłówek grupy: padding:12px 16px border-bottom:1px #DCE0E6 font:14px/500 color:#000 gap:8px. Etykieta = „Dzień D miesiąc" (np. „Poniedziałek 5 sierpnia"). Licznik: font:11px/400 kolor #222693 tło #F3F3FF 22×22 radius:15px padding:4px. Lista wizyt: flex-column gap:8px padding:12px.
Wizyta: radius:6px font:12px/16px. Tło = color stanowiska (jasny), tekst = text stanowiska. Main: flex gap:8px padding:6px 6px 6px 4px. Pasek: width:3px radius:2px = border stanowiska. Body (list-layout): flex-row align-center gap:12px. Czas: font-weight:400. Tytuł (marka+model): font-weight:500. Opis: ellipsis. Status: chip bg:rgba(0,0,0,.04) padding:4px 8px radius:2px font:12px, kropka 8×8 = border statusu. Wydane: opacity:.5.
